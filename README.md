# 単位セーフティ

大学生・専門学生向けに「あと何回休めるか」「期末試験であと何点必要か」「最終成績は何点になるか」を計算できるWebサービスです。出席や成績の数字から、単位取得までの見通しを確認できます。

## 主な機能

- **出席セーフティ**：総授業回数、現在までの授業回数、欠席回数、必要出席率から、現在の出席率と追加で欠席できる回数を計算します。出席条件を満たせない見込みの場合は警告します。
- **必要点数計算**：合格ライン、課題・中間試験の点数と割合、期末試験の割合から、確定済みの成績、合格までの不足点、期末試験の必要点数・得点率を計算します。到達済み・取得不可能な場合も表示します。
- **最終成績シミュレーター**：課題・中間試験・期末試験の点数と割合から、最終成績を予測します。S（90点以上）・A（80点以上）・B（70点以上）・C（60点以上）・不可（60点未満）の簡易評価を表示します。

## 使用技術

- HTML
- CSS
- JavaScript

外部API、フレームワーク、外部フォントは使用していません。ビルド不要の静的サイトです。

## 特徴

- 登録不要
- 無料で利用可能
- スマートフォン対応
- 入力したデータを外部に送信しない（保存機能もありません）
- Cloudflare Pagesで公開可能
- キーボード操作、結果の読み上げ通知、入力エラーの表示に対応
- 使い方とFAQをページ内に掲載

## 使い方

1. `index.html`をブラウザで開き、使いたいツールに授業や成績の数字を入力します。
2. 各カードの計算ボタンを押します。
3. 結果とメッセージを確認します。入力を変更したら再度計算してください。

最初に表示される数字と結果は入力例です。必要点数計算と最終成績シミュレーターでは、各点数を100点満点、割合の合計を100%として入力します。割合は最終成績全体に占める比率です。シラバスに「課題30%」と記載されている場合は30を入力してください。

必要点数計算の初期値では、課題80点×30%＋中間70点×30%＝45点が確定済みです。合格ライン60点まであと15点なので、割合40%の期末試験では37.5点以上（得点率37.5%）が必要になります。期末の割合が0%で合格ラインに届いていない場合は、取得不可能と表示します。

## 公開について

Cloudflare Pagesで公開できる静的ファイル構成です。公開するディレクトリの直下に`index.html`、`style.css`、`script.js`を配置してください。依存パッケージのインストール、ビルド、APIキー、環境変数、サーバー側の処理は不要です。

## 注意事項

計算結果は参考値です。実際の単位認定・出席条件・評価方法は、各学校・授業のシラバスや担当教員の案内を確認してください。点数上の合格ライン到達は、単位取得を保証するものではありません。

出席セーフティは必要な出席回数を切り上げて計算し、遅刻・早退の換算は含みません。成績計算は入力した割合による加重平均を使用し、学校独自の端数処理や追加の必須条件は含みません。簡易評価は表示用に丸める前の点数で判定します。
