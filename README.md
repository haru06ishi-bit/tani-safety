# 単位セーフティ

大学生・専門学生向けに「あと何回休めるか」「期末試験であと何点必要か」「最終成績は何点になるか」を計算できるWebサービスです。出席や成績の数字から、単位取得までの見通しを確認できます。

公開URL：[https://tani-safety.pages.dev/](https://tani-safety.pages.dev/)

## 主な機能

- **出席セーフティ**：総授業回数、現在までの授業回数、欠席回数、必要出席率から、現在の出席率と追加で欠席できる回数を計算します。出席条件を満たせない見込みの場合は警告します。
- **必要点数計算**：合格ライン、課題・中間試験の点数と割合、期末試験の割合から、確定済みの成績、合格までの不足点、期末試験の必要点数・得点率を計算します。到達済み・取得不可能な場合も表示します。
- **最終成績シミュレーター**：課題・中間試験・期末試験の点数と割合から、最終成績を予測します。S（90点以上）・A（80点以上）・B（70点以上）・C（60点以上）・不可（60点未満）の簡易評価を表示します。

## 使用技術

- HTML
- CSS
- JavaScript

外部API、フレームワーク、外部フォントは使用していません。ビルド不要の静的サイトです。

## 特徴

- 登録不要
- 無料で利用可能
- スマートフォン対応
- 入力したデータを外部に送信しない（保存機能もありません）
- Cloudflare Pagesで公開可能
- キーボード操作、結果の読み上げ通知、入力エラーの表示に対応
- 使い方とFAQをページ内に掲載

## 使い方

1. `index.html`をブラウザで開き、使いたいツールに授業や成績の数字を入力します。
2. 各カードの計算ボタンを押します。
3. 結果とメッセージを確認します。入力を変更したら再度計算してください。

最初に表示される数字と結果は入力例です。必要点数計算と最終成績シミュレーターでは、各点数を100点満点、割合の合計を100%として入力します。割合は最終成績全体に占める比率です。シラバスに「課題30%」と記載されている場合は30を入力してください。

必要点数計算の初期値では、課題80点×30%＋中間70点×30%＝45点が確定済みです。合格ライン60点まであと15点なので、割合40%の期末試験では37.5点以上（得点率37.5%）が必要になります。期末の割合が0%で合格ラインに届いていない場合は、取得不可能と表示します。

## 公開について

Cloudflare Pagesで公開できる静的ファイル構成です。公開するディレクトリの直下に`index.html`、`style.css`、`script.js`、`favicon.svg`、`og-image.png`、`robots.txt`、`sitemap.xml`を配置してください。依存パッケージのインストール、ビルド、APIキー、環境変数、サーバー側の処理は不要です。

## SEO・SNS共有対応

- 日本語として自然なページタイトルとmeta descriptionを設定しています。
- `favicon.svg`をheadの`link rel="icon"`から読み込みます。
- OGPにタイトル・説明・種類（website）・公開URL・サイト名・言語・共有画像・画像サイズ（1200×630）・代替テキストを設定しています。
- Twitter Cardは`summary_large_image`形式で、タイトル・説明・共有画像を設定しています。
- OGPとTwitter Cardの画像URLは`https://tani-safety.pages.dev/og-image.png`です。画像を`index.html`と同じ階層に配置し、一緒にデプロイしてください。
- 現在の画像ファイルの実サイズは1729×910pxです。指定されたmetaタグの1200×630とは異なります。公開前に画像を1200×630pxで書き出し直すと、宣言サイズと一致します。
- canonicalと`og:url`は`https://tani-safety.pages.dev/`に統一しています。
- FAQPageのJSON-LD構造化データをheadに記載しています。FAQの質問・回答を変更する際は、画面のFAQとJSON-LDを同時に更新してください。
- `robots.txt`はすべての検索エンジンのクロールを許可し、`https://tani-safety.pages.dev/sitemap.xml`を案内します。
- `sitemap.xml`にはトップページの正規URLのみを掲載しています。

### Search Console対応

Google Search Consoleの所有権確認用metaタグ（`google-site-verification`）を、`index.html`のhead内にある`Google Search Console verification`コメントの直後へ追加済みです。公開サイトへデプロイした後、Search Consoleで所有権確認を行い、`sitemap.xml`を送信してください。タグの追加だけでは所有権確認の完了を意味しません。

公開URLを変更する場合は、canonical・OGP・robots.txt・sitemap.xml・このREADMEのURLをまとめて更新してください。

## 注意事項

計算結果は参考値です。実際の単位認定・出席条件・評価方法は、各学校・授業のシラバスや担当教員の案内を確認してください。点数上の合格ライン到達は、単位取得を保証するものではありません。

出席セーフティは必要な出席回数を切り上げて計算し、遅刻・早退の換算は含みません。成績計算は入力した割合による加重平均を使用し、学校独自の端数処理や追加の必須条件は含みません。簡易評価は表示用に丸める前の点数で判定します。
